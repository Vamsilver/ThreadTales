# Animation System — Стандарты анимаций и интеграция с GASPALS

> **Краткая суть:** Стандарты анимаций, правила интеграции с плагином GASPALS, слоты воспроизведения и обязательные требования к UEFN-скелету.

---

## 1. Главные правила и абсолютные запреты

1. **ИСКЛЮЧИТЕЛЬНО UEFN скелет:**
   * В проекте ThreadTales разрешено использовать анимации и монтажи **ТОЛЬКО на UEFN скелете** (`SK_UEFN_Mannequin`).
   * Запрещены Mixamo, UE4 Mannequin или сторонние риги без предварительного ретаргета на целевой UEFN скелет.
2. **Только `DefaultGroup.DefaultSlot`:**
   * В AnimBP плагина GASPALS (`ABP_SandboxCharacter`) выходная поза подключена через слот `DefaultGroup.DefaultSlot`.
   * Монтажи со сторонними слотами (`Ledge_Climbing` и др.) **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНЫ** — они приводят к застыванию меша в Т-позе при перемещении капсулы по Root Motion.
3. **Обязательный Root Motion в `AnimSequence` паркура:**
   * Если в клипе перемещается кость `root`, в исходном ассете `AnimSequence` **ОБЯЗАТЕЛЬНО** должны быть выставлены:
     * `bEnableRootMotion = True`
     * `bForceRootLock = False`
   * **Почему это критично:** Если `bEnableRootMotion = False`, движок не извлекает дельту корня. Скелетный меш смещается внутри капсулы, пока C++ одновременно двигает саму капсулу (двойное смещение). При окончании монтажа меш рывком отлетает назад в капсулу, вызывая судорожные взмахи руками.
4. **Обязательная кривая `foot_alpha = 0.0`:**
   * Во всех монтажах паркура (вис, шимми, прыжки, угловые переходы, подъем) **ОБЯЗАТЕЛЬНО** должна присутствовать кривая `foot_alpha` со значением `0.0` на всем протяжении клипа.
   * **Почему это критично:** Без этой кривой нодовая подсистема Foot IK в `ABP_SandboxCharacter` пытается притянуть стопы к предыдущей стене или полу. Это скручивает таз, перекашивает позвоночник и ломает плечевой пояс персонажа.
5. **Бесшовный Crossfade монтажей (`PlayLength - BlendOutTime`):**
   * В C++ коде длительность любого переходного паркурного состояния (`TransitionDuration`) рассчитывается как:
     `Duration = FMath::Max(Montage->GetPlayLength() - Montage->BlendOut.GetBlendTime(), 0.1f);`
   * **Почему это критично:** Если таймер равен полной длине `PlayLength`, монтаж успевает затухнуть за время `BlendOut`, и персонаж на 0.2 с проваливается в базовую позу AnimGraph (эффект «проскальзывания чужой анимации») перед включением виса.
6. **Ручной ретаргет и импорт:**
   * Импорт и ретаргетинг выполняет исключительно пользователь вручную через Unreal Editor. AI-агент не запускает скрипты ретаргета.

---

## 2. Интеграция с GASPALS

* **Главный Anim Blueprint:** `/GASPALS/Blueprints/ABP_SandboxCharacter` (Read-only, не модифицировать).
* **Motion Matching:** использует базы поз `UPoseSearchDatabase` и таблицы выбора `UChooserTable`.
* **Боевые позы (Overlay System):** смена стойки с оружием реализуется через оверлей-систему GASPALS (`ABP_LayerBlending`) и библиотеку `UThreadTalesMotionMatchingLibrary::SetCombatStanceActive(bool)`.

---

## 3. Стандарты настройки AnimMontage

| Параметр | Стандарт для прыжков / паркура | Стандарт для атак / комбо |
|---|---|---|
| **Слот** | `DefaultGroup.DefaultSlot` | `DefaultGroup.DefaultSlot` |
| **Blend In Time** | `0.10 с` (`HERMITE_CUBIC`) | `0.10 .. 0.15 с` |
| **Blend Out Time** | `0.20 с` (`HERMITE_CUBIC`) | `0.20 .. 0.25 с` |
| **Blend Out Trigger Time** | **`-1.0`** (строго не выходить досрочно) | `-1.0` (или по окну комбо) |
| **Root Motion (Sequence)** | `EnableRootMotion = True`, `ForceRootLock = False` | `EnableRootMotion = True` |
| **Foot IK Curve** | **`foot_alpha = 0.0` (ОБЯЗАТЕЛЬНО)** | По умолчанию |
| **Зацикливание (Loop)** | `Default -> Default` (только для висов `Hang`) | Нет |
